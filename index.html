Eco-Loop

Autonomous LLM agent for closed-loop building energy control (2026)

Python FastAPI Model Context Protocol (MCP) Ollama (Llama 3.1) EnergyPlus pytest

An agent-based AI system where a locally-hosted open-source LLM (Ollama / Llama 3.1) plans and executes control actions through a custom MCP tool-calling server, exchanging observations and actions with an EnergyPlus physics simulation over a REST/JSON boundary.

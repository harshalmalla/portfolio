About

AI agents are the part I actually enjoy. Most of what I build ends up with a check sitting between what the model proposes and what the system is allowed to do, because giving a model direct control over something real still seems like a bad idea to me. Eco-Loop started as a hackathon problem statement and became the project I learned the most from. The hardest thing I have debugged so far was not an agent at all: it was keeping job data in sync in real time across three roles in Bay Manager.

Projects

Eco-Loop

Autonomous LLM agent for closed-loop building energy control (2026)

Python FastAPI Model Context Protocol (MCP) Ollama (Llama 3.1) EnergyPlus pytest

An agent-based AI system where a locally-hosted open-source LLM (Ollama / Llama 3.1) plans and executes control actions through a custom MCP tool-calling server, exchanging observations and actions with an EnergyPlus physics simulation over a REST/JSON boundary. A deterministic, Pydantic-validated safety layer gates every LLM-proposed setpoint before actuation. Covered by an automated pytest suite spanning the REST API, the MCP handshake, and the comfort validator.
